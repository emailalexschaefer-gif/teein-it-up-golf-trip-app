# Mobile verification checklist — Presentation UX polish (Samsung, 12 Oct 2026)

## Entry flow
- [ ] My HQ → Stage 5 Create Presentation opens **Event Memories home** (group photo, Upload Moments, gallery). No popup.
- [ ] The round chip (R1/R2/R3 or All) matching the scope is highlighted.
- [ ] Tap **Create Slideshow** → "Which Memories should we include?" appears → Favourites / All / Choose still work → Sections → Review → Play.
- [ ] Back from the slideshow / refresh the page: popup does **not** re-open on its own.
- [ ] Tap a different round chip, then Create Slideshow: you get the normal round/Full Event picker.
- [ ] Open Memories directly (not from My HQ): Create Slideshow → picker as before.
- [ ] Event with no photos: Create Slideshow still reachable from My HQ.

## Event Snapshot (full-event presentation, landscape full screen)
- [ ] Title on one line (or two max for very long names), not overlapping EVENT SNAPSHOT.
- [ ] EVENT SNAPSHOT directly below the title.
- [ ] Four numbers equally prominent, aligned to the gold dividers.
- [ ] Course names readable, left of the divider line area, **not on the golf ball**, not touching the bottom-right logo.
- [ ] Rounds / Holes / Side Games / Event Champion values match the event; tie shows 2+, no champion shows 0.
- [ ] The title shows the trip's real name ("- Slide Show" will remain until the trip is renamed).
- [ ] Also check portrait phone (letterboxed) and, if possible, cast to a TV.

## Moments & Bloopers
- [ ] Portrait photo (e.g. Rocky): green/gold EVENT MOMENTS card in the right pillarbox, photo untouched, nothing over faces.
- [ ] Landscape photo: small pill top-left only.
- [ ] Portrait video Blooper: BLOOPERS card; video plays, mute button works, slides still advance on time.
- [ ] Unassigned event upload in the Moments & Bloopers chapter reads EVENT MOMENTS, not BLOOPERS.
- [ ] Label absent on: opening, group photo, winners, champion, leaderboard, Moments & Bloopers divider, closing.
- [ ] Controls (prev/play/next, ✕) still tap through the label area.

## Regression spot checks
